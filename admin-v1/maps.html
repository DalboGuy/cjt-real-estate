7 · Portal Navigation Flow

The user can always return to the left navigation without using the browser Back button.

Built
Current ModuleDashboard, Reservations, Documents, Admin, etc.
↓
Menu › Flyoutpersistent left-edge return control when pane is hidden
→
Sliding Left Panescrollable module list · active item kept visible

Desktop: the pane can collapse and reopen. Mobile: the same control opens the slide-out drawer. The browser Back button is not required to get back to portal navigation.
